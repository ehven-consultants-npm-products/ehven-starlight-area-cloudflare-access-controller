# Changelog

## 1.0.0

- Compile independent protected areas from explicit paths and rosters with optional expiring grants.
- Support explicit preview eligibility, optional discovery, and independent host admission.
- Verify Cloudflare Access credentials and authorize protected requests before serving content.
- Provide typed ESM entry points and optional Starlight components for access identity, locked navigation, and shared-search restrictions.
- Preserve existing numbered course catalogs and allow applications to opt into enrollment-based preview eligibility.

For stable 1.x, breaking changes require a major version. Compatible additions use a minor version, and compatible fixes use a patch version.
