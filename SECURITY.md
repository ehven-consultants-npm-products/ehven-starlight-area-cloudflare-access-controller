# Security

Report suspected vulnerabilities privately to [security@ehven.com](mailto:security@ehven.com). Include the affected version, deployment type, observed impact, and a minimal example with synthetic data. Keep credentials, Access assertions, rosters, and private content out of the report.

Security fixes target the latest stable 1.x release. Confirmed issues are addressed in a new release and a security notice when appropriate. Upgrade and redeploy the affected Worker, verify authorization for protected routes and assets, and revoke or rotate any exposed credentials. Preserve both the Cloudflare Access gate and the origin's membership checks during remediation.

Use [GitHub Issues](https://github.com/ehven-consultants-npm-products/ehven-starlight-area-cloudflare-access-controller/issues) for ordinary support. Keep vulnerability reports private during triage.
